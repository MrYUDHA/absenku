# AbsensiBot — Chatbot Absensi Karyawan

Prototipe website untuk demonstrasi final project. Dibuat dengan HTML, CSS, dan JavaScript tanpa instalasi library.

## Fitur
- Check-in dan check-out dengan waktu perangkat.
- Status absensi hari ini.
- Riwayat absensi yang tersimpan pada `localStorage`.
- Chatbot sederhana dengan kata kunci: `bantuan`, `status`, `riwayat`, `jam kerja`, `check-in`, dan `check-out`.
- Tampilan responsif untuk laptop dan ponsel.

## Cara menjalankan
1. Ekstrak folder project.
2. Buka `index.html` menggunakan browser modern.
3. Tekan Check-in / Check-out dan coba chatbot.

## Cara mengunggah ke GitHub
1. Masuk atau daftar di GitHub.
2. Buat repository baru bernama `absensibot`.
3. Unggah file `index.html`, `style.css`, `app.js`, dan `README.md`.
4. Setelah terunggah, salin URL repository untuk dimasukkan ke formulir final project.
5. Untuk menayangkan demo, buka **Settings → Pages**, pilih branch `main` dan folder `/ (root)`, lalu simpan. Tunggu sampai GitHub Pages memberikan alamat situs.

## Batasan penting
Ini adalah **prototipe frontend untuk demonstrasi**, bukan sistem absensi produksi. Data tersimpan hanya pada browser/perangkat yang digunakan, belum dibagikan antar-karyawan dan tidak dikirim ke server. Waktu berasal dari jam perangkat dan belum diverifikasi. Jangan gunakan untuk data absensi resmi sebelum menambahkan backend, autentikasi, database, validasi waktu, serta kebijakan privasi dan keamanan.
